## Documentación de referencia

**MDN Web Docs** — https://developer.mozilla.org/gl/
A referencia máis completa e fiable de CSS (e de HTML, JavaScript, etc.). Ten partes en galego, pero a maioría está en inglés. **É a primeira fonte a consultar.**

**W3C — CSS Specifications** — https://www.w3.org/Style/CSS/
As especificacións oficiais. Son moi técnicas, pero útiles cando hai dúbidas sobre detalles concretos.

**CSS Snapshot** — https://www.w3.org/TR/css-2026/
Documento que recolle o estado de todos os módulos CSS nun momento dado.

**Baseline** — https://web.dev/baseline
Estado de compatibilidade das características web. Moi útil para saber se unha característica se pode usar en produción.

**Can I use** — https://caniuse.com/
Base de datos de compatibilidade de características CSS, HTML e JavaScript.

## Aprender e practicar

**web.dev — Learn CSS** — https://web.dev/learn/css
Curso completo de CSS de Google, con leccións interactivas. Moi recomendado.

**web.dev — Learn Responsive Design** — https://web.dev/learn/design
Curso específico de deseño adaptativo.

**CSS-Tricks** — https://css-tricks.com/
Artigos, guías e trucos. A súa guía de Flexbox e a de Grid son referencia mundial.

**Smashing Magazine — CSS** — https://www.smashingmagazine.com/category/css
Artigos en profundidade sobre CSS.

**Ahmad Shadeed** — https://ishadeed.com/
Artigos visuais moi claros sobre CSS moderno.

**Lea Verou** — https://lea.verou.me/
Unha das persoas máis influentes no mundo do CSS.

**The A11Y Project** — https://www.a11yproject.com/
Recursos prácticos de accesibilidade.

### Formas e efectos

- **Clippy** — https://bennettfeely.com/clippy/
  Xerador visual de `clip-path`.
- **Cubic-Bezier** — https://cubic-bezier.com/
  Ferramenta visual para curvas de aceleración.
- **Fancy Border Radius** — https://9elements.github.io/fancy-border-radius/
  Xerador de `border-radius` complexos.

### Layout

- **Flexbox Froggy** — https://flexboxfroggy.com/#gl
  Xogo interactivo para practicar Flexbox.
- **Grid Garden** — https://cssgridgarden.com/#gl
  Xogo interactivo para practicar Grid.

### Documentación de estilo

- **CSS Guidelines** — https://cssguidelin.es/
  Guía de estilo moi recomendada para proxectos grandes.
- **BEM** — https://getbem.com/
  Convención de nomes de clases.

## Ferramentas de desenvolvemento

- **Chrome DevTools** — integrado no navegador. Panel de rendemento, de capas, de accesibilidade.
- **Firefox Developer Tools** — integrado no navegador. Panel de grid e flexbox moi potente.
- **axe DevTools** — extensión de navegador para auditar accesibilidade.
- **Lighthouse** — integrado en Chrome DevTools para auditar rendemento, accesibilidade, SEO.
- **WebPageTest** — https://www.webpagetest.org/ — medición de rendemento en dispositivos reais.
