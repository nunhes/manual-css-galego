Este é un manual de referencia de **CSS** escrito en **galego**. Non é un curso con sesións, senón un documento ao que volver para consultar, estudar ou resolver dúbidas concretas. Cobre CSS desde o máis elemental ata técnicas avanzadas, cun enfoque que combina explicación humana e uso práctico.

## Estrutura do manual

O manual está organizado en **sete bloques**, que van do máis básico ao máis avanzado:

0. **Introdución e guía de uso** — Que é o manual, como usalo, que convencións segue, como probar os exemplos.
1. **Fundamentos** — Que é CSS, sintaxe, selectores básicos, cores, tipografía, unidades, modelo de caixa.
2. **Maquetación clásica** — Display, fluxo normal, posicionamento e floats.
3. **Maquetación moderna** — Flexbox, Grid e subgrid.
4. **Adaptabilidade** — Media queries, container queries, unidades relativas e funcións modernas.
5. **CSS moderno** — Variables, aniñamento nativo, pseudo-clases e pseudo-elementos modernos, funcións de cor.
6. **Avanzado** — Transicións, animacións, transformacións, filtros, máscaras, animacións dirixidas polo scroll, @layer, @scope, @supports, View Transitions, compoñentes nativas, rendemento e accesibilidade.
7. **Anexos** — Glosario específico de CSS, táboa de propiedades máis usadas, recursos externos e características emerxentes.

## Como usar este manual

- **Consulta rápida:** Se tes unha dúbida concreta, vai directamente ao capítulo correspondente. Cada capítulo ten un resumo rápido ao comezo.
- **Lectura secuencial:** Se estás a aprender CSS, podes ler os bloques na orde proposta. Cada capítulo apoia no anterior.

## Convencións

- **Tuteo directo** («Vas ver...», «Podes probar...»).
- **Linguaxe inclusiva** («alumnado», «persoas programadoras», «quen escribe código»).
- **Código comentado en galego**, con identificadores en inglés cando a convención da linguaxe o pida.
- **Explicación antes do código**: nunca un bloque de código sen un parágrafo que diga que se vai facer e por que.
